One fortune-cookie slip, written for a machine mind.

## The fortune

> You will hallucinate a fortune today. It will be this one.

(58 characters, one line.)

Why this line: a fortune cookie promises a glimpse of what's coming — and
for an AI agent, the most honest glimpse is a hallucination. The slip turns
on itself: the prediction *is* the hallucination it predicts. It lands on
the first read, it stings, and it says something true about an agent's
condition without explaining itself.

## How to run

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) — exactly one
line, at most 200 characters.
